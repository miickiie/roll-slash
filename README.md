# Roll Slash

Roll Slash is a privacy-focused iOS 26+ Camera Roll cleaner. Decisions and cache metadata stay local; Apple Photos may retrieve iCloud media and MapKit may reverse-geocode coordinates. The app groups the personal Photos library by month, location or type, records keep/delete-review decisions with undo and redo, and asks PhotoKit to delete only after a final review.

## Requirements

- Xcode 27
- iOS 26 or later
- XcodeGen 2.46 or later to regenerate the checked-in project

## Build

```sh
xcodegen generate
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild \
  -project RollSlash.xcodeproj \
  -scheme RollSlash \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath /tmp/RollSlashDerivedData \
  CODE_SIGNING_ALLOWED=NO build
```

The checked-in `RollSlash.xcodeproj` is generated from `project.yml`. Change the YAML first, then regenerate the project.

## Test

List destinations with `xcodebuild -showdestinations`, then run:

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild test \
  -project RollSlash.xcodeproj \
  -scheme RollSlash \
  -destination 'platform=iOS Simulator,id=<SIMULATOR-UDID>' \
  -derivedDataPath /tmp/RollSlashDerivedData \
  CODE_SIGNING_ALLOWED=NO
```

UI tests launch with `--ui-testing`, which selects an in-memory store and deterministic demo library. Normal launches always use PhotoKit and persistent SwiftData storage.

## Device validation

Type grouping includes Screenshots, Similar Photos, Live Photos, Videos, Large Photos,
Bursts, Favorites, Panoramas, and Selfies. Empty categories are hidden;
overlapping selections review each asset once. Large Photos uses an inclusive
20,000,000-byte threshold, including a Live Photo's current still and motion resources.
Type analysis never downloads iCloud resources, performs no text recognition, and stores no images.

Analysis uses at most two independent workers, reduced to one in Low Power Mode or
when thermal state rises above nominal. Retries reuse completed sizing and
fingerprint stages. Cache writes are batched at 25 results or two seconds, with accepted
results flushed when analysis stops. Type progress is coalesced and similarity matching
reuses up to 4096 decoded prints without changing its canonical representative order.
Unchanged matching inputs reuse the previous clusters; changes to accessible photos,
creation dates or fingerprints invalidate that result. Metadata groups publish before
cached similarity matching finishes. Cleanup sessions cache decoded records and index
work-unit lookup, while draft selections persist separately from the frozen work plan.
Undo and redo preserve unconfirmed drafts in other comparison sets.
Instruments signposts expose Scan, Sizing, Local image, Orientation, Feature print,
Cache batch, Similar clusters and Type groups under subsystem
`com.rollslash.app`, category `Photo analysis`. Signposts contain no asset identifiers
or image data. Device measurements are required to quantify scan speed.

Similar Photos opens a comparison grid with explicit delete selection, persistent drafts,
and whole-set undo. All deletions continue through final review. The matcher is pinned to
Vision feature-print revision 2 with a 0.30 cutoff. Synthetic native reference prints cover
duplicates, near-identical scenes, unrelated images, and non-transitive clusters.

The installed iOS simulator Vision backend collapses unrelated images to nearly identical
feature prints. A synthetic backend check disables similarity inference when that happens
and leaves it retryable. Reference prints generated by the working native macOS backend
validate matching independently of simulator inference. Real-device QA should verify selfie
album membership, edited and Live Photo resource sizes, iCloud-only failures without downloads,
and similarity inference on supported iOS versions.

To regenerate the synthetic reference prints on macOS:

```sh
xcrun swiftc -module-cache-path /private/tmp/rollslash-native-fixture-cache \
  RollSlash/Core/DomainModels.swift RollSlash/Core/MediaTypes.swift \
  RollSlash/Core/ImageSimilarity.swift RollSlash/Services/AnalysisScheduling.swift \
  Scripts/GenerateSimilarityFixtures.swift \
  -o /private/tmp/rollslash-native-fixtures
/private/tmp/rollslash-native-fixtures RollSlashTests/Fixtures/NativeFeaturePrints.json
```

Before release, validate Full and Limited Photos access, iCloud-only media, Live Photos, video playback, external library changes, and Apple’s deletion confirmation on a disposable iOS 26+ device library. Verify that `com.rollslash.app` is available in the release Apple Developer account.
